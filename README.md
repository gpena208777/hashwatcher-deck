# HashWatcher for Braiins Deck

Customers install the widget here:

**https://hashwatcher.app/deck.html**

That page has the `.nar` download and steps. After install, re-pair from **HashWatcher → Braiins Remote**.

This repository is also the release channel for Deck auto-updates (`deck/release.json` plus the versioned `.wasm` and `.nar` on GitHub Releases).

The widget source is in `src/`. The Tailscale opt-in the Tailscale button is supposed to start is described in [TAILSCALE.md](./TAILSCALE.md).
